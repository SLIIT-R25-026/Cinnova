Follow these steps to create a new APK after making changes to your app:

PREREQUISITES
========================================
✅ Make sure you have your changes saved
✅ Ensure you're in the main project directory: /Users/ravindurasanga/Desktop/RP025/MyApp

========================================
METHOD 1: EXPO PREBUILD + GRADLE (RECOMMENDED)
========================================

STEP 1: Navigate to Project Directory
--------------------------------------
cd /Users/ravindurasanga/Desktop/RP025/MyApp

STEP 2: Update Version (Optional but Recommended)
-------------------------------------------------
Edit app.json and increment version:
- Change "version": "1.0.0" to "1.0.1" (or next version)
- Change "versionCode": 1 to 2 (or next number)

STEP 3: Clean Previous Build
----------------------------
npx expo prebuild --platform android --clean

STEP 4: Build New APK
---------------------
cd android
./gradlew assembleRelease

STEP 5: Locate Your APK
-----------------------
Your APK will be at:
./app/build/outputs/apk/release/app-release.apk

STEP 6: Copy APK to Desktop (Optional)
--------------------------------------
cp ./app/build/outputs/apk/release/app-release.apk ~/Desktop/Cinnova-v1.0.1.apk

========================================
METHOD 2: EAS BUILD (CLOUD BUILD)
========================================

STEP 1: Navigate to Project Directory
--------------------------------------
cd /Users/ravindurasanga/Desktop/RP025/MyApp

STEP 2: Login to EAS (if not already logged in)
-----------------------------------------------
npx eas login

STEP 3: Build APK via EAS
-------------------------
npx eas build --platform android --profile apk

STEP 4: Download APK
--------------------
Once build completes, run:
npx eas build:download --platform android --latest

Or visit: https://expo.dev/accounts/mr.mind/projects/cinnova/builds

========================================
TROUBLESHOOTING COMMON ISSUES
========================================

Issue: "Duplicate AppTheme" Error
---------------------------------
Solution: Check and fix styles.xml:
nano /Users/ravindurasanga/Desktop/RP025/MyApp/android/app/src/main/res/values/styles.xml
Make sure there's only ONE AppTheme definition.

Issue: Build Cache Problems
----------------------------
Solution: Clean everything:
cd android
./gradlew clean
cd ..
npx expo prebuild --platform android --clean

Issue: Metro Bundler Cache
--------------------------
Solution: Reset Metro cache:
npx react-native start --reset-cache
Or:
npm start -- --reset-cache

Issue: Node Modules Problems
----------------------------
Solution: Reinstall dependencies:
rm -rf node_modules
npm install
